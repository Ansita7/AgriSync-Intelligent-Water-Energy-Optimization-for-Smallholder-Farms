FRONTEND SETUP:
cd frontend && npx create-react-app . && npm install axios react-router-dom recharts

BACKEND SETUP:
cd backend && python -m venv venv && source venv/bin/activate && pip install -r requirements.txt

TO SETUP:
1. git clone <your-repo>
2. cd AgriFlex
3. Create folders: mkdir -p frontend/src/{pages,components,styles,services}
4. Create folders: mkdir -p backend/app/{routes,services}
5. Download each file above to correct location
6. Rename files (remove prefix and extension)
